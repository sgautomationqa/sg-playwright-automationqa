# Playwright Automation Framework

## Project Overview

This project is a real-world Playwright automation framework developed using JavaScript and Page Object Model (POM) design pattern.

The framework covers important automation concepts including:

* Page Object Model (POM)
* Fixtures
* Assertions
* Waits
* Dynamic test data
* Window handling
* Dropdown handling
* Popup handling
* GitHub integration

## Run Tests

Run all tests:

npx playwright test

Run in headed mode:

npx playwright test --headed

Run specific file:

npx playwright test tests/ecommerce.spec.js --headed
